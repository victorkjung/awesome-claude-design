1Prompt Anatomy

A great prompt has four moves. Order matters — words near the front pull harder.

[image URL] subject + action, style, composition + lighting, mood --ar 3:2 --s 250 --v 7

Worked example

a tired astronaut sipping espresso, neo-noir oil painting, cinematic close-up, volumetric rim light, melancholy --ar 3:2 --s 350 --v 7
  • Subject — who/what + what they're doing.
  • Style — medium / artist movement / era.
  • Composition + light — angle, lens, lighting.
  • Mood — one or two emotional words.

3Image, Style & Character Refs

Paste one or more image URLs before your text. They influence subject + composition.

4Multi-prompts & Weights

Split a prompt into chunks with ::. Add a number to weight a chunk. Negative numbers act like --no.

space:: ship --v 7     # two ideas, equal weight
hot::2 dog             # prioritize "hot" (a temperature)
cyberpunk city ::1 rain::-.5  # discourage rain
  • Bare :: = weight 1 by default.
  • Decimals work: ::.5 halves the influence.
  • Negative weights total must stay net-positive.

5Permutations

Run multiple jobs at once with {a, b, c} — MJ expands every combination.

a {red, teal, golden} {fox, owl} in a forest --ar 3:2 --v 7
# → 6 separate jobs (3 colors × 2 animals)
  • Escape commas inside braces with \, if you need a literal one.
  • Use /fast mode — permutations burn GPU minutes fast.
  • Confirms before launching when count > 3.

10Tips That Actually Work

  • Front-load the subject. Words near the start get more weight than words at the end.
  • Be specific, not adjective-stacked. "a librarian's hands cupping a paper crane" beats "beautiful detailed amazing hands".
  • One style per prompt. "watercolor + 3D render + photoreal" usually fights itself — pick one.
  • Use --no, never "no X". "no text" in a prompt sometimes adds text. Use --no text, watermark, signature.
  • Lock the look: save a --sref code or --p code for an entire series.
  • Iterate cheap. --q .5 + /fast for exploration, then upscale only the keepers.
  • Reproduce a result: react with ✉️ on a job to DM the seed + job ID, then re-run with --seed.
  • Aspect ratio changes everything. Same prompt at 9:16 vs 21:9 is basically a different image.
  • Use /describe on an image you love → steal the structure of the prompt, replace the subject.
  • Stylize ladder. 50 (literal) → 100 (default) → 250 (stylish) → 750 (decorative) → 1000 (chaos).
